# Chauffeur Empire — Product Brief

## What is this?

A browser MMO about building a luxury chauffeur empire from scratch. The player starts with nothing and scales through hiring drivers, buying vehicles, winning corporate contracts, and dominating rivals.

## Who plays it?

Players who enjoy idle/incremental tycoon games with depth — economy simulation, PvP mechanics, political systems. Audience: Italian-speaking, 18–40, familiar with eRepublik / browser strategy games.

## Core loop

1. Generate rides → earn cash
2. Hire drivers + buy vehicles → automate rides
3. Expand fleet → unlock new regions
4. Compete in contracts, auctions, P2P market → passive income
5. Progress quests → earn VTK + DC → reinvest

## Key screens

| Tab | Purpose | Frequency |
|---|---|---|
| Home (Command Center) | Daily overview: earnings, active rides, notifications | Every session |
| Dispatch | Ride queue: assign drivers manually or auto-dispatch | Frequent |
| Fleet | Vehicle management: repair, upgrade, buy | Moderate |
| Staff | Driver hire/fire, academy, stress management | Moderate |
| Career | Mission journal, quest tree, VTK rewards | Occasional |
| Finance | Stocks, loans, bonds, Bloomberg dashboard | Power users |
| Contracts | B2B tender bidding against AI | Active players |
| Tourism | PvP bidding for luxury tourism contracts | Active players |
| HQ | Base building across 5 Italian cities | Progression |
| Premium Store (Executive Club) | Buy DC, spend DC on boosters | Monetization |
| VTK Market | P2P trade VTK ↔ DC | Economy |

## Business model

- Free to play
- Driver Coins (DC) = premium currency, purchasable
- VTK (Vettura Token) = earned-only, tradeable P2P for DC
- Goal: DC not required to progress, only to accelerate

## Current phase

Beta / pre-launch. UI being polished. Core gameplay loop complete.

## User goals per session

- Check earnings from offline time
- Dispatch new rides
- Complete 1–2 quests
- Check B2B / tourism contracts
- Optionally: manage staff, buy vehicles, monitor stocks

## Pain points to solve

- Too many tabs = decision paralysis → sidebar accordion helps
- Information density too high → eRepublik flat style reduces cognitive load
- Early game: not enough cash to act → quest rewards should feel generous
